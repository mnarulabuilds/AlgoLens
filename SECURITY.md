# Security Policy

## Supported versions

Security fixes are applied to the latest release on the `master` branch.

## Reporting a vulnerability

If you discover a security issue, please **do not** open a public GitHub issue.

Instead, report it privately by emailing the repository owner through GitHub's security advisory flow, or via the bug report form on the live site if you have a non-sensitive contact path.

Include:

- A description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if any)

We aim to acknowledge reports within 7 days.

## Scope

In scope:

- The AlgoLens web application and its build/deploy pipeline
- Client-side data handling (localStorage, env vars baked at build time)

Out of scope:

- Third-party services (Web3Forms, GitHub Pages infrastructure)
- Social engineering or physical attacks
